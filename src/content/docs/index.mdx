## First request

Authenticate with a reveal-once credential and call the regional endpoint that credential encodes.

```bash
curl --fail-with-body \
  --header "Authorization: Bearer $TEAMGRID_API_TOKEN" \
  --header 'Accept: application/json' \
  https://api.de.teamgrid.app/v1/workspace
```

The response identifies the authenticated workspace, its region, and its cell. The
[quickstart](/api/v1/quickstart/) covers creating the credential, listing tasks, and paginating with
cursors.

## Interfaces

API v1 is the source of truth. The other three interfaces are clients of it rather than independent
integration surfaces.

<div class="interface-index">
  <a href="/api/v1/">
    <span class="interface-index__name">API v1</span>
    <span class="interface-index__note">The versioned HTTP contract: scoped credentials, regional ingress, cursor pagination, idempotent creates, and signed webhooks.</span>
  </a>
  <a href="/sdk/">
    <span class="interface-index__name">TypeScript SDK</span>
    <span class="interface-index__note">A typed Node.js client with regional routing, bounded retries, timeouts, pagination iterators, and versioned errors.</span>
  </a>
  <a href="/cli/">
    <span class="interface-index__name">CLI</span>
    <span class="interface-index__note">Inspect and automate TeamGrid from a terminal or a CI job, with structured output and stable exit codes.</span>
  </a>
  <a href="/mcp/">
    <span class="interface-index__name">MCP server</span>
    <span class="interface-index__note">An optional local stdio adapter with a deliberately bounded read-only tool surface, using the same credentials as the CLI.</span>
  </a>
</div>

API v1 `1.0.0-rc.1` governs 181 operations across 111 paths. That number measures contract parity
across the HTTP API, SDK, and CLI, not complete TeamGrid product coverage. The
[capability ledger](/guides/capability-coverage/) records the remaining partial, planned, and private
areas explicitly, and [choose an interface](/guides/choose-an-interface/) maps common integration
shapes to a recommended surface.
